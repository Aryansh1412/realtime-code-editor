# 🚀 Real-Time Collaborative Code Editor

A real-time collaborative code editor built with the **MERN Stack** and **Socket.io** that allows multiple users to write code together, communicate via live chat, and collaborate using unique room IDs.

## ✨ Features

- Real-time collaborative code editing
- Create and join unique rooms
- Username-based room access
- Integrated live chat
- Instant code synchronization using Socket.io
- Responsive user interface

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB

## ⚙️ Installation

```bash
git clone https://github.com/your-username/realtime-code-editor.git
cd realtime-code-editor
```

Install dependencies:

```bash
cd client
npm install

cd ../server
npm install
```

Run the project:

```bash
# Backend
cd server
npm run dev

# Frontend
cd client
npm run dev
```

Open: `http://localhost:5173`
